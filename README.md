# SEEKHO feedback

Public feedback for **SEEKHO**, an interview-prep sequencer for AI/LLM engineering roles.

Comments posted on the SEEKHO website's feedback wall land in [Discussions](https://github.com/Kcodess2807/seekho-feedback/discussions) (via [giscus](https://giscus.app)). Suggest a topic or a source, report a stale link, or upvote an idea.

This repository holds no code; SEEKHO's source is private.
